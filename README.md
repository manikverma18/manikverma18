## 🚀 Featured Projects

### 🛡️ GraphSentinel — Zero-Day Lateral Movement Detection
*Smart India Hackathon 2025 • Top 20 Teams*

A network security system that detects suspicious lateral movement in enterprise networks using **Graph Neural Networks** and temporal network analysis.

- Models network entities as **nodes** and communications as **temporal edges** in a dynamic graph
- Trained temporal edge GNN integrated with a **Flask** inference backend that returns detection probabilities and anomaly scores
- **React/Vite dashboard** with network graph, detection panel, flow table, probability gauge, and alert/threat cards
- APIs tested with **Postman**; built collaboratively using Git feature branching and pull requests

**Tech:** `Python` `PyTorch` `Flask` `React` `Vite` `REST API` `Postman` `Git`

🔗 [View Repository](https://github.com/manikverma18/Graph-Neural-Networks)

### 🏥 HDIMS — Healthcare Database Information & Management System
*Project and Research Expo 2025 • 🥈 2nd Prize*

A secure, **role-based** healthcare information management system for structured storage and management of patient records.

- Relational schema designed in **MySQL** and normalized to **3NF** to reduce redundancy
- Optimized SQL queries for efficient insertion and retrieval
- **Role-based access control** for secure, controlled access to records
- Presented architecture, database design, and business value to a judging panel

**Tech:** `MySQL` `SQL` `3NF Normalization` `Access Control`

🔗 [View Repository](https://github.com/manikverma18/Health-Data-Information-and-Management-System)
